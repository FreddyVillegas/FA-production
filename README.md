# FA-production

Repositorio central para organizar y conservar la memoria técnica, operativa y administrativa del estudio de producción musical de Freddy Villegas.

## Cómo se organiza

- **[`constitution.md`](constitution.md):** reglas de colaboración entre Freddy y ChatGPT.
- **[`orchestrator.md`](orchestrator.md):** mapa de documentos e instrucciones para encontrar la información correcta.
- **`data/`:** información detallada del estudio, equipo, clientes, proyectos, compras y agenda.
- **`history/`:** historial de cambios y decisiones relevantes.

## Cómo trabajar con este repositorio

Antes de trabajar en el proyecto, consultar la constitución y el orquestador. Después, leer y actualizar los documentos temáticos correspondientes. Cada dato debe mantenerse en un único documento principal para evitar contradicciones y duplicados.

La estructura crecerá gradualmente conforme exista información que documentar; no se crearán archivos vacíos por adelantado.
